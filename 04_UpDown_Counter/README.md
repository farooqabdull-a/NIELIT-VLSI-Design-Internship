# Assignment 04 — Combinational Logic Design: 4-bit Up/Down Counter

## Overview
Behavioral 4-bit up/down counter, implemented with both **synchronous** and **asynchronous** reset. Verified for both up-counting and down-counting operation.

| Path | Description |
|---|---|

| `rtl/up_down_counter_async.v` | Asynchronous-reset up/down counter |
| `testbench/tb_up_down_counter_sync.v` | Testbench — synchronous version |
| `testbench/tb_up_down_counter_async.v` | Testbench — asynchronous version |
